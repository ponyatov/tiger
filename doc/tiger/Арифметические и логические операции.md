# Арифметические и логические операции

Арифметические и логические операции составляют основу вычислительной логики любой программы. В OCaml эти операции реализованы в строгом соответствии с системой типов, что обеспечивает безопасность и предсказуемость вычислений. В данной главе рассматриваются базовые операторы для работы с числовыми и логическими типами данных, их синтаксис, семантика и особенности использования.

## int

- Бинарные операции
	- Деление `/` является **целочисленным** (отбрасывается дробная часть).
    
	- Операция `mod` возвращает остаток от деления с тем же знаком, что и делимое (по математическому определению).
    
	- При делении на ноль возникает исключение `Division_by_zero`.

```ocaml
3 + 4    (* сложение → 7 *)
10 - 5   (* вычитание → 5 *)
6 * 7    (* умножение → 42 *)
15 / 4   (* целочисленное деление → 3 *)
15 mod 4 (* остаток от деления → 3 *)
```
- Унарные операции
```ocaml
- 5      (* унарный минус → -5 *)
- (-3)   (* двойное отрицание → 3 *)
```

## float

Для вещественных чисел используются специальные операторы с точкой (`.`) в суффиксе. Это отличает OCaml от многих других языков и предотвращает неявное смешивание целых и вещественных типов.

- Базовые операции
```ocaml
3.0 +. 4.5    (* сложение → 7.5 *)
10.0 -. 2.5   (* вычитание → 7.5 *)
2.0 *. 3.14   (* умножение → 6.28 *)
10.0 /. 3.0   (* деление → 3.33333333333 *)
```
- Унарные операции
```ocaml
-. 5.0      (* унарный минус → -5.0 *)
abs_float (-3.14) (* модуль → 3.14 *)
```
- Специальные операции
```ocaml
2.0 ** 3.0    (* возведение в степень → 8.0 *)
sqrt 4.0      (* квадратный корень → 2.0 *)
exp 1.0       (* экспонента e¹ → 2.71828182846 *)
log 10.0      (* натуральный логарифм → 2.30258509299 *)
sin (3.14 /. 2.0) (* синус π/2 → ~1.0 *)
cos 0.0       (* косинус 0 → 1.0 *)
```

## Операции сравнения

Операторы сравнения в OCaml работают с разными типами данных, но всегда возвращают значение типа bool (true или false). Большинство операторов сравнения полиморфны по первому аргументу.

```ocaml
3 < 5     (* меньше → true *)
10 > 5    (* больше → true *)
4 <= 4    (* меньше или равно → true *)
7 >= 8    (* больше или равно → false *)
```
```ocaml
5 = 5     (* равенство → true *)
5 = 3     (* равенство → false *)
5 <> 3    (* неравенство → true *)
5 <> 5    (* неравенство → false *)
```
- Сравнение вещественных чисел
```ocaml
3.0 < 5.0     (* true *)
3.14 = 3.14   (* true, но осторожно с точностью! *)
```
- Для безопасного сравнения вещественных чисел с учётом погрешности вычислений рекомендуется использовать функции из модуля Float:
```ocaml
Float.compare 3.14 3.141 (* возвращает -1, 0, 1 *)
Float.equal 1.0 1.0000000001 ~epsilon:1e-9 (* сравнение с допуском *)
```

## bool

Логические операции работают только со значениями типа `bool` (`true` или `false`).

```ocaml
true && false  (* логическое И → false *)
true || false  (* логическое ИЛИ → true *)
not true       (* отрицание → false *)
```

OCaml использует **ленивое вычисление** (short-circuit evaluation) для операторов `&&` и `||`:

- Для `&&`: если левый операнд равен `false`, правый операнд не вычисляется.
    
- Для `||`: если левый операнд равен `true`, правый операнд не вычисляется.

Логические операции часто используются в условных выражениях:
```ocaml
let is_even n = (n mod 2 = 0)
let is_positive n = (n > 0)
let is_positive_even n = is_even n && is_positive n
```

## Побитовые операции (только для `int`)

```ocaml
let a = 0b1100  (* двоичное 12 *)
let b = 0b1010  (* двоичное 10 *)

a land b   (* побитовое И → 0b1000 (8) *)
a lor b    (* побитовое ИЛИ → 0b1110 (14) *)
a lxor b   (* исключающее ИЛИ → 0b0110 (6) *)
lnot a     (* побитовое НЕ → -13 (зависит от представления) *)

a lsl 2    (* сдвиг влево → 0b110000 (48) *)
a lsr 1    (* логический сдвиг вправо → 0b0110 (6) *)
a asr 1    (* арифметический сдвиг вправо → 0b0110 (6) для положительных *)
```
