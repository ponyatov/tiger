# Особенности языка

## Статическая типизация

Каждое выражение в OCaml имеет строго определённый тип, который проверяется во время компиляции. Это предотвращает целый класс ошибок, связанных с несоответствием типов, которые в динамически типизированных языках проявляются только во время выполнения.

## Вывод типов

Компилятор OCaml способен автоматически определять типы выражений без явных аннотаций. Это достигается благодаря алгоритму алгоритму Хиндли-Милнера, который анализирует код и выводит наиболее общий тип для каждого выражения.

## Функциональное ядро

В основе OCaml лежит функциональная парадигма:

- Функции являются **объектами первого класса** (их можно передавать как аргументы, возвращать как результаты)
    
- Поддержка **каррирования** (частичного применения функций)
    
- **Неизменяемые структуры данных** по умолчанию
    
- **Сопоставление с образцом** (pattern matching) для декомпозиции данных

## Эффективность

OCaml компилируется в эффективный нативный код, производительность которого сравнима с языками уровня C/C++. Это достигается благодаря:

- Статической типизации (отсутствие накладных расходов на проверку типов в runtime)
    
- Оптимизирующему компилятору **ocamlopt**
    
- Управлению памятью через **сборку мусора** с инкрементальным сборщиком
