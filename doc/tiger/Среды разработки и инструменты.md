# Среды разработки и инструменты

- **[[opam]]**
	- менеджер компиляторов, позволяет установить несколько разных версий, и переключаться между ними
	- управляет установкой компилятора, библиотек и их версий

```sh
bash -c "sh <(curl -fsSL https://opam.ocaml.org/install.sh)"
opam init --bare --disable-sandboxing -a
which opam
```
```
/usr/local/bin/opam
```

A [[OCaml/switch|switch]] is a named installation of OCaml with a particular compiler version and set of packages. You can have many switches and, well, switch between them —whence the name.

```sh
$ opam switch list
$ opam switch set default ; eval $(opam env --switch=default)
```
```
#  switch   compiler                                           description
→  cs3110    ocaml-base-compiler.5.3.0,ocaml-options-vanilla.1  ocaml-base-compiler = 5.3.0
   default  ocaml-base-compiler.5.4.0,ocaml-options-vanilla.1  ocaml >= 4.05.0
```

## [[utop]]: интерактивная среда (REPL)

OCaml предоставляет две интерактивных среду выполнения, запускаемых командами:
- `ocaml`
	- поставляется из коробки в пакете компилятора
- **[[utop]]**
	- расширенный REPL

```sh
$ opam install -y utop dune ocamlformat ocaml-lsp-server
$ opam install -y ppx_string menhir
```
```
[NOTE] Package ocaml-lsp-server is already installed (version 1.23.0).
[NOTE] Package ocamlformat is already installed (version 0.27.0).
[NOTE] Package dune is already installed (version 3.20.2).
[NOTE] Package utop is already installed (version 2.16.0).
```
- [[utop]] the OCaml Universal Toplevel
- [[OCaml/dune|dune]] OCaml build system
- [[OCaml/ocamlformat|ocamlformat]] source autoformatting tool
- [[ocaml-lsp-server]] [[LSP]] Language Server Protocol server for IDE integration

## Компиляторы

- **[[ocamlc]]**
	- компилятор в байт-код (для быстрой разработки и отладки)
- **[[ocamlopt]]**
	- оптимизирующий компилятор в нативный код (для production)
- **[[OCaml/dune|dune]]**
	- система сборки проектов
