# Определение переменных с помощью `let`

В языке OCaml, как и в его предшественниках из семейства ML, оператор `let` служит основным средством для связывания имён со значениями. Это связывание является **статическим** и **неизменяемым** — после определения значение переменной не может быть изменено в пределах её области видимости. Такой подход соответствует принципам функционального программирования, где данные по умолчанию иммутабельны.

## Базовый синтаксис

Простая форма определения переменной:

```ocaml
let <идентификатор> = <выражение>
```
Примеры:
```ocaml
let x = 42                     (* целое число *)
let pi = 3.14159265359        (* вещественное число *)
let language = "OCaml"         (* строка *)
let is_compiled = true         (* булево значение *)
```

## Локальные связывания и область видимости

Для создания переменных с ограниченной областью видимости используется конструкция `let ... in`:
```ocaml
let area radius =
  let pi = 3.14159 in
  let r_squared = radius *. radius in
  pi *. r_squared
```

- `pi` и `r_squared` существуют только внутри функции `area`
    
- После вычисления выражения после `in` эти переменные становятся недоступными

## Связывание с использованием сопоставления с образцом

Оператор `let` может использоваться с различными образцами для деструктуризации данных:
```ocaml
let (x, y) = (5, 10)           (* разложение кортежа *)
let [a; b; c] = [1; 2; 3]      (* разложение списка *)
let {name; age} = {name = "Alice"; age = 30}  (* разложение записи *)
```
