# интерполяция строк

Интерполяция строк — это возможность вставлять значения переменных или выражений непосредственно в строковые литералы, что упрощает форматирование текста. В отличие от некоторых других языков (таких как Python или JavaScript), OCaml **не поддерживает нативную интерполяцию строк**. Однако существуют проверенные библиотечные методы для достижения аналогичного результата.

## `Printf.sprintf`

Основным инструментом для форматирования строк в OCaml является модуль `Printf`. Функция `sprintf` позволяет создавать строки с использованием форматных спецификаторов, аналогичных функциям семейства `*printf` языка C:

```ocaml
let name = "Ольга"
let age = 30
let greeting = Printf.sprintf "Привет, %s! Тебе %d лет." name age
(* greeting = "Привет, Ольга! Тебе 30 лет." *)

let pi = 3.14159
let circle_info = Printf.sprintf "π ≈ %.2f, площадь круга: %.3f" pi (pi *. 10.0 *. 10.0)
```

Для вывода отформатированной строки в стандартный вывод используется функция `printf`:

```ocaml
let x = 5
let y = 7
Printf.printf "Сумма %d и %d равна %d\n" x y (x + y)
(* Вывод: Сумма 5 и 7 равна 12 *)
```

### Спецификаторы формата `*printf`

```ocaml
%s    (* строка *)
%d    (* целое число (десятичное) *)
%i    (* целое число *)
%f    (* вещественное число *)
%b    (* булево значение *)
%c    (* символ *)
%o    (* восьмеричное число *)
%x    (* шестнадцатеричное число (нижний регистр) *)
%X    (* шестнадцатеричное число (верхний регистр) *)
%e    (* вещественное число в экспоненциальной форме *)
%E    (* то же, но с 'E' *)
%g    (* вещественное число в кратчайшей форме *)
%G    (* то же, но с 'E' *)
%%    (* символ процента *)
```

## [[ppx_string]]

Для более удобной интерполяции строк, напоминающей синтаксис других языков, можно использовать библиотеку `ppx_string`. Эта библиотека предоставляет синтаксическое расширение ([[ppx]]), позволяющее использовать строковые литералы с встроенными выражениями.

> cначала необходимо подключить библиотеку в проекте

```ocaml
let name = "Алексей"
let score = 95
let message = [%string "Игрок %{name} набрал %{score} очков."]
(* message = "Игрок Алексей набрал 95 очков." *)
```

Сначала убедитесь, что библиотека установлена в вашем текущем окружении opam:
```sh
opam install -y ppx_string
```

Если библиотека ещё не установлена, эта команда загрузит и установит её вместе со всеми зависимостями.

Использование в проекте прописывается через dune-файл:
```lisp
 (libraries ppx_string)
 (preprocess (pps ppx_string))
```

### Простая интерполяция

Основной синтаксис — это `[%string "..."]`. Внутри строки используйте `%{...}` для подстановки выражений

```ocaml
let user = "Алексей"
let score = 95
let message = [%string "Игрок %{user} набрал %{score} очков."]
(* message = "Игрок Алексей набрал 95 очков." *)
```

### Работа с нестроковыми типами

По умолчанию для вставки ожидается тип string. Для нестроковых типов можно использовать преобразователи:

```ocaml
let port = 8080
let command = [%string "ssh host -p %{port#Int}"]
(* автоматически вызывает `Int.to_string` *)
```
- `%{some#Mod}` преобразуется в вызов `Mod.to_string some`

### Выравнивание в поле

- `%{expr#Mod:int_expr}` выравнивает вывод `Mod.to_string expr` в поле шириной не менее `int_expr` пробелов
- `%{expr#:int_expr}` выравнивание для строки
