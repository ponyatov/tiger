# Создание нового проекта dune

## Структура проекта

```sh
$ dune init project tiger
```
```
dune-project  конфигурационный файл проекта
bin/          
	dune      файл для сборки
	main.ml   исходный код исполняемого файла
lib/
	dune
	lib.ml    исходный код библиотеки
test/
	dune
	test.ml   код тестов
_build/       артефакты сборки
.gitignore    исключения Git
```

Так как мы будем генерировать код на embedded С/С++, у этих языков принята несколько другая структура каталогов проекта. Тем не менее, `dune` достаточно гибкий, чтобы вынести весь OCaml-код в один каталог `lib`:

- [[tiger/dune-project|dune-project]]
- `tiger.opam` файл проекта для [[opam]] генерируется из `dune-project`
- `bin/` целевой каталог для откомпилированных бинарных программ и образов прошивок
	- `.gitignore`
		```
		*
		!.gitignore
		```
- выходные файлы транслятора
	- `inc/`
		- `hci.hpp` заголовочный файл (декларации)
	- `src/`
		- `hci.cpp` код С++ сгенерированный транслятором
- `lib/` код на Ocaml
	- `hello.ml` пример исполняемого файла
		```ocaml
		let () = 
		  (* блочный коментарий *)
		  print_endline "Hello, OCaml!"
		```
	- `hci.ml`библиотека
	- [[tiger/dune|dune]]
