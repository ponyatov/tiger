# Базовые типы данных

## `int`: целые числа

- знаковые целые $\pm 2^{63}$
- один бит используется для представления внутренних указателей

```ocaml
let x:int = 42
let y = -17
let z = 0
```

- операции с целыми числами:

```ocaml
3 + 4    (* сложение → 7 *)
10 - 5   (* вычитание → 5 *)
6 * 7    (* умножение → 42 *)
15 / 4   (* целочисленное деление → 3 *)
15 mod 4 (* остаток от деления → 3 *)
```

## `float`: вещественные числа


```ocaml
let pi = 3.14159
let e = 2.71828
let temperature = -5.5
```
- используются специальные операторы с точкой
```ocaml
3.0 +. 4.5    (* сложение → 7.5 *)
10.0 -. 2.5   (* вычитание → 7.5 *)
2.0 *. 3.14   (* умножение → 6.28 *)
10.0 /. 3.0   (* деление → 3.33333333333 *)
```

## `bool`: булевы значения

- только два значения: `true` & `false`

```ocaml
let is_valid = true
let has_error = false
```

- логические операции:

```ocaml
true && false  (* логическое И → false *)
true || false  (* логическое ИЛИ → true *)
not true       (* отрицание → false *)
3 < 5          (* сравнение → true *)
10 = 10        (* равенство → true *)
```
